# NSDash

Sistema de gestión y análisis de rendimiento deportivo para preparadores físicos.

NSDash permite registrar entrenamientos de fuerza, pruebas de velocidad y VAM (Velocidad Aeróbica Máxima), realizar seguimiento de atletas y visualizar métricas de rendimiento mediante un dashboard moderno.

---

# Características

## Fuerza
- Gestión de atletas.
- Registro de entrenamientos.
- Estimación automática de 1RM.
- Historial de progresión.
- Tablas de porcentajes.

## Velocidad
- Registro de sprints.
- Registro de pruebas VAM.
- Cálculo automático de zonas de entrenamiento.
- Conversión entre unidades de velocidad.
- Tablas de entrenamiento.
- Historial de evolución.

## Autenticación
- Login mediante JWT.
- Usuarios protegidos.
- Cada entrenador accede únicamente a sus atletas.
